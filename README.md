| Metric | Result |
|---|---|

- 트러블슈팅: PySpark/Python 버전 충돌, Java 호환성, Kafka `ADVERTISED_LISTENERS` 오설정, 디스크 OOM, 체크포인트 손상
- 초기 PR-AUC = 1.0 결과의 **라벨 순환(leakage) 문제를 직접 발견·수정**
